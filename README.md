# 🏫 "交我办" 网球场空位监控器

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Playwright](https://img.shields.io/badge/playwright-v1.40+-green.svg)](https://playwright.dev/python/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

这是一个专为“交我办”设计的**网球场空位监控与自动警报工具**。实时监控“东区网球场”和“胡晓明网球场”的预约状态，一旦检测到目标时段有空闲场地，会立即通过声光报警提醒您，网页端还支持单场空位的自动抢单功能。

---

## 🌟 重点功能

- **🚀 双模式监控驱动**
  - **网页版监控**：基于现代浏览器自动化技术，直接操作网页端，支持在发现**唯一符合条件的空位时自动提交订单**。
  - **PC模拟器监控**：支持与电脑端“交我办”模拟器应用无缝联动，采用后台静默检测技术，**完全不占用您的真实鼠标和键盘**。
- **📅 智能日期自适应**
  - 系统能根据当前的本地时间，智能生成最合理的默认监控日期。例如：中午 12:00 放场前自动调整天数，深夜 21:00 网球场关闭后自动将监控起点顺延至次日。
- **🔔 即时声光警报**
  - 监控过程中一旦发现符合条件的空闲场地，程序会立即将窗口置顶，并循环播放警报铃声，确保您在第一时间内获知信息并进行预约。
- **🔒 隐私与安全保障**
  - **零密码保存**：程序绝不收集或保存任何您的 jAccount 账号与密码，所有的登录均在交我办官方页面中安全完成。
  - **本地凭证安全**：登录成功后的会话凭证加密存储于本地，下一次启动时只要凭证未过期即可直接免密进入监控，安全无忧。

## 📂 项目结构

项目代码结构清晰、模块化设计，主要包含以下部分：

```text
交我办抢场/
├── sjtu_tennis_monitor/          # 项目核心代码包
│   ├── browser/                  # 网页版自动化监控与自动下单模块
│   ├── pc/                       # PC 模拟器版连接与界面操作驱动模块

│   ├── constants.py              # 全局配置常量（包含场馆名称等）
│   ├── models.py                 # 数据结构定义（如场地信息、时间段等）
│   ├── config.py                 # 命令行参数解析与日期自适应规则
│   ├── exceptions.py             # 异常处理模块
│   └── alarm.py                  # 警报铃声循环播放器
├── requirements.txt              # Python 第三方依赖包列表
├── 启动监控器.bat                 # 双击一键启动网页版监控
└── 启动PC版监控器.bat             # 双击一键启动 PC 模拟器版监控
```

## ⚙️ 快速开始与使用

### 1. 环境准备
确保您的 Windows 系统已安装 **Python 3.8+**。在项目根目录下打开命令行，运行以下命令安装必要的运行依赖：
```bash
# 安装项目依赖
pip install -r requirements.txt

# 安装网页版所需的浏览器核心
python -m playwright install chromium
```

### 2. 启动监控
- **网页监控版**：直接双击运行 [启动监控器.bat](启动监控器.bat)（或在终端运行 `python -m sjtu_tennis_monitor`）。
- **PC模拟器版**：直接双击运行 [启动PC版监控器.bat](启动PC版监控器.bat)（或在终端运行 `python -m sjtu_tennis_monitor --pc`）。

### 3. 使用步骤
1. **设定目标条件**：在启动后的界面中，勾选您想要监控的场馆（“东区网球场” / “胡晓明网球场”），输入您期望的时间段（如 `18:00` 到 `21:00`），并确认监控日期。
2. **一次登录，免密复用**（网页版）：首次使用时，程序会拉起浏览器界面，点击“校内人员登录”后在手机端扫码登录即可。之后运行程序将自动复用本地登录状态。
3. **静默监控与警报**：点击“开始监控”后，程序将以安全的时间间隔循环检测。发现空场时将立即响起警报，点击“停止报警”即可静音。

## ⚠️ 注意事项与避坑指南

- **🔒 自动下单的安全限制（仅限网页版）**：
  为防止下单错误，**只有当本轮检测中“有且仅有 1 个”符合您设定条件的空场时**，系统才会触发自动下单。如果同时出现多个符合条件的空位，为稳妥起见，程序**只报警、不触发下单**，需您手动选择并提交。
- **🔌 PC版模拟器运行要求**：
  运行 PC/ADB 版监控前，请确保您本地的电脑版“交我办”（内置模拟器环境）能够正常运行，并且其桌面快捷方式 `交我办.lnk` 存在，且虚拟机内部的“开发者选项 - USB 调试”保持开启状态。
- **⏱️ 刷新频率与防限流限制**：
  为了保障交我办校园服务器的稳定运转，刷新间隔不建议设置得过低（默认建议在 20 秒 or 以上，最低限制为 10 秒）。如果因为刷新过快导致交我办系统返回限流提示，程序将自动进入冷却期并中止监控，次日零点后方可自动恢复。
