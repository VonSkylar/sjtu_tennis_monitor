# 交我办网球场空位警报器

这是一个 Windows 本地小工具，用来监控交我办里"东区网球场"和"胡晓明网球场"的指定日期和时间段是否出现空场。它只读取页面状态并报警，不会点击场地格子，也不会提交预约。

## 项目结构

```
交我办抢场/
├── sjtu_tennis_booking/          # 主包
│   ├── __init__.py               # 包元信息
│   ├── __main__.py               # python -m sjtu_tennis_booking 入口
│   ├── constants.py              # 常量定义
│   ├── models.py                 # 数据模型
│   ├── exceptions.py             # 自定义异常
│   ├── config.py                 # 配置解析与限流管理
│   ├── alarm.py                  # 报警音
│   ├── browser/                  # 浏览器版（Playwright）
│   │   └── monitor.py            # VenueMonitor
│   ├── pc/                       # PC/ADB 版
│   │   ├── adb.py                # ADBController
│   │   ├── driver.py             # PCBookingDriver
│   │   └── monitor.py            # PCVenueMonitor
│   └── gui/                      # tkinter GUI
│       ├── browser_app.py        # 浏览器版 GUI
│       └── pc_app.py             # PC 版 GUI
├── pyproject.toml                # 包配置
├── requirements.txt              # 依赖
├── 启动监控器.bat                 # 双击启动浏览器版
├── 启动PC版监控器.bat             # 双击启动 PC/ADB 版
└── browser_profile/              # 浏览器会话（运行时生成）
```

## 安装

在本目录打开 PowerShell，执行：

```powershell
pip install -r requirements.txt
python -m playwright install chromium
```

## 运行

**浏览器版**（Playwright 自动化）：

```powershell
python -m sjtu_tennis_booking
```

**PC/ADB 版**（Androws Android 自动化）：

```powershell
python -m sjtu_tennis_booking --pc
```

也可以双击对应的 `.bat` 文件启动。

窗口打开后：

1. 输入日期。可以是单日 `2026-05-17`，多个日期 `2026-05-17,2026-05-18`，也可以是日期范围 `2026-05-11~2026-05-18`。程序启动时会自动填默认日期：中午 12:00 前默认今天起 7 天，12:00 及以后默认今天起 8 天，21:00 及以后默认明天起 7 天。
2. 输入开始和结束时间，例如 `18:00` 到 `20:00`。
3. 设置刷新间隔。默认 `20` 秒，最小 `10` 秒。
4. 勾选要监控的场馆。默认勾选"东区网球场"，也可以只选"胡晓明网球场"，或两片场都选。
5. 如需自动下单，勾选"唯一符合条件空场自动下单"。默认开启（仅浏览器版支持）。
6. 点击"开始监控"。
7. 程序会打开浏览器。若尚未登录，程序会自动点击"校内人员登录"；进入 jAccount 后请手动扫码或输入验证码登录一次。登录成功后程序会按所选场馆打开对应的预约页。
8. 程序按设置的刷新间隔检查一轮。每片已选场馆都会维护自己的标签页，并在多个日期之间轮流检查。
9. 发现空场后会弹窗并持续响铃，点击"停止报警"即可静音。弹窗会显示具体场馆、日期、时间和场地。

## 注意事项

- 第一次登录后，浏览器会话保存在本目录的 `browser_profile` 文件夹，后续通常不需要重复登录。程序不会保存账号密码；如果学校的 jAccount 登录态过期，仍需要手动完成一次扫码或验证码登录。
- 如果某个目标日期没有出现在页面顶部日期标签里，程序会跳过该日期并继续检查其他日期。
- 如果某片场馆页面没有停留在网球场预约表格，程序会提示你检查对应标签页。
- 默认每 20 秒检查一轮，最小可设为 10 秒。只选一片场馆时，监控 8 天一轮完整检查大约需要 4 分钟；同时选择两片场馆时，请求量约翻倍。
- 自动下单开启后，只有本轮所有已选场馆里恰好发现 1 个符合条件的空场时，程序才会选中该空场、点击"立即下单"、勾选须知并点击"提交订单"。如果发现多个空场，只报警不下单。
- 如果页面提示"每日请求超过限制，无法获取"，程序会弹出错误提醒并停止监控。
- 触发请求次数上限后，本地无法恢复学校服务器额度。程序会记录到 `rate_limit_until.txt`，并阻止继续监控到次日 00:10，避免继续刷新。
- 报警音使用普通 WAV 音频循环播放，比系统蜂鸣更容易从蓝牙耳机输出。请确认 Windows 默认输出设备和音量混合器都指向你的耳机。
- 程序不会保存账号密码。
